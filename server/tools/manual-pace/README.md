# 手动操作节奏采样

运行根目录的 **手动节奏采样.cmd**，或运行 node server/tools/manual-pace/recorder.cjs --open。

默认使用「手动记录每轮」，配合普通 Chrome：

1. 关闭自动投递桌面助手，点「打开 BOSS 网页」，准备好要浏览的岗位。
2. 点「开始采样」，按平常速度完成一轮：选岗、读详情、按需查看公司、决定是否沟通、处理后续弹窗。
3. 回到操作表点「完成这一轮」。下一轮准备好后点「开始下一轮」，重复3–5轮。
4. 临时离开先暂停。最后点「结束并保存」，记录保存在 data/manual-pacing 下，也可导出。
5. 告诉助手「采样完成」，再按真实样本调整调度参数。工具本身不自动修改参数。

手动模式只测整轮用时，不声称采集到了逐步点击或阅读时间。切回操作表结束这一轮所用的时间仍会计入该轮；两轮之间的准备时间不计入任意一轮。暂停期间时间排除。发送、投递和反馈均由用户决定，工具不替用户操作。手动模式不连接浏览器调试接口、不读取网页或认证资料、不读取或清除项目的账号暂停记录。

「自动记录每步（专用窗口）」使用只读的页面事件监听，保存类型与时间，不保存岗位/公司名称、链接、输入值、Cookie 或聊天正文。已在全部请求拦截的离线网页上验证可信点击、公司页、沟通/继续沟通及移除监听；本机真实专用窗口多次断开，尚未完成真实稳定性验证，因此不作为默认采样方式。浏览器关闭或进入登录/验证页面时暂停自动计时，不自动重新打开。

自动模式中：下一次选岗结束上一轮。页面就绪观察有短暂延迟，分阶段时长只是近似值；每轮总时长以可信点击为边界。点击不能证明消息实际发送，所以只显示「已点沟通」。只在取得有效样本后分析节奏，不编造固定秒数，也不据此宣称能避免平台限制。

验证：

- node --test server/tools/manual-pace/model.test.cjs：时间边界、暂停排除、分位数。
- node server/tools/manual-pace/recorder.test.cjs：隔离临时目录里的手动两轮、暂停恢复、保存、禁止覆盖；没有启动浏览器或访问 BOSS。
- node server/tools/manual-pace/observer.test.cjs：临时浏览器与离线网页，全部请求拦截，没有真实投递。
