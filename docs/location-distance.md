# 位置与距离筛选（2026-10-07）

自动定位使用 Windows 系统定位；地图选点和公共地址搜索继续使用 Leaflet / OpenStreetMap / Nominatim，不需要用户申请 Key。出发位置与已保存的最大直线距离保持不变。

## 废弃交通时长筛选

真实长测中的 BOSS 内部地图弹窗多次返回与岗位地址不能可靠关联的终点。原实现又要求地址文本完全一致、坐标相差小于两米，并依赖内部 Vue 状态；部分路线能读到，部分失败。即使查询成功，AI 等待或累计休息超过十分钟后路线证据会过期，导致岗位反复进入待确认。

没有稳定的、已验证的路线来源可替代这条链路，因此删除公交／地铁时长选项、原生地图查询、路线缓存及旧的 BOSS 地址搜索入口。不会用直线距离推算交通分钟数。

旧配置中的 maxTransitMinutes 在配置归一化和下次保存时移除，保留 origin 与 maxDistanceKm。旧待确认记录可继续读取；交通失败和过期字段不再参与判断，投递前按最新岗位工作地址重新计算距离。

## 当前行为

- 坐标转换与直线距离计算在本机完成，不打开 BOSS 地图弹窗或查询路线。
- 超出保存的公里上限直接淘汰；距离边界使用实际值比较。
- 缺少真实工作地址或坐标时保留待确认，不使用公司注册地址或城市中心替代。
- 界面明确说明直线距离不是交通路程或通勤时间。
