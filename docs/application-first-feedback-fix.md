# 投递优先、反馈范围与输入修复（2026-10-07）

## 原因

- 提示词把“简历未提供兴趣、工具或作品证明”当成能力不符合；普通熟练使用工具被升级成硬资格。
- 每个低分结果都调用不合适反馈，并默认同时屏蔽整家公司。
- 普通控件仅半秒间隔，详情与提交之间看起来接连完成。
- 需求词和排除词每次输入都立即拆分、去空项、重新拼接，吞掉末尾逗号及正在编辑的空格。

## 修改

- 提示词采用投递优先，区分未写与明确冲突。内容策划、运营、剪辑属于可迁移能力；不自动要求游戏爱好、文字作品集或逐项工具证明。仅因未提及而被低分的旧格式返回也能直接放行，不额外调用 AI。
- 真实硬资格须同时有岗位与用户连续原文，才认定冲突。未提供证照只进入待确认；原有语言硬条件与用户工作条件仍分别核对。
- AI 低分和缓存低分均不反馈不合适。城市、薪资、学历、距离、招聘者活跃度不符也不反馈；只在真实内容命中用户主动排除的行业、公司或岗位时提交平台内置反馈。
- 岗位排除只影响该岗位；公司行业、主营或名称排除才影响整家公司。界面显示范围；内部判断理由仍不上传。
- 普通动作至少 1 秒、详情选择 3.5 秒、投递写入 2.5 秒、翻页 5 秒。不在已通过岗位的沟通前叠加 16 秒停顿；发送后的确认保持短间隔。读页面与 AI 用时计入间隔。
- 输入框保存原始编辑文字，配置单独保存解析后的列表；支持中英文逗号、顿号、分号和换行。
- 与现场日志逐条对应，备份后撤销 3DMGAME、恬艮、上海壹念、人瑞网络科技 4 条本地误屏蔽。此操作不撤销已发给 BOSS 的历史反馈。

## 验证

- 3DM 原始 52 分理由、常见编辑工具缺证明可投；明确无关保持低分；硬资格未提供待确认；虚构候选人引文不采信。
- 批量投递中 AI 低分不触发平台或本地屏蔽；明确金融、助贷、销售等排除仍生效。
- 真 Chrome CDP 反馈选择公司与岗位范围、发送后的确认；本地屏蔽范围跨重启。
- 模拟时钟验证全页面队列和实际间隔；停止、明确限频、验证保留。
- 界面逐字输入逗号/中文词/分号、保存配置及刷新还原；前后端构建和桌面启动回归。
