# 公司详情页停留与关闭修复

2026-10-09。

原流程打开核对页后立即读取 DOM，并在 finally 中直接请求关闭标签；打开动作的间隔没有覆盖页面停留和关闭。

公司详情页现采用内部 3000ms 最短打开时间，从页面创建完成开始计时，加载和读取耗时计入。已耗足时间不重复等待。原人工记录未包含公司页样本，此值是暂定工程参数，不是实测阅读时间或平台阈值，不增加用户设置。

等待使用任务作用域，可响应停止或暂停。关闭通过页面操作适配进入共享导航队列。等待前、等待后及关闭前检查当前登录和验证状态，异常页面保留并置前。读取失败仍遵循停留；关闭失败保留连接，避免误报页面已关闭。简历编辑与完整岗位核对不增加公司页的停留，但关闭同样进入队列。

验证：npm run test:company-pacing 和 npm run test:pace-calibration 通过，服务端编译通过。测试采用虚拟时间、模拟页面和本地关闭响应，没有使用真实账号浏览或投递。
