# 学历筛选、AI 设置与 Git 管理

日期：2026-10-01

## 学历筛选

原逻辑把学历当作岗位标签白名单：默认本科/硕士排除了要求大专的岗位。现在“筛选规则 → 我的最高学历”为单选；本科满足大专/专科及本科的最低门槛，硕士满足本科及以下，博士满足硕士及以下。低于岗位最低要求时仍会拒绝，岗位明确仅限某学历时保留该限制。

旧的本科/硕士多选配置迁移为本科，避免把本科用户推断为硕士；学历不设置时不做这一项硬筛。简历和手动要求两种 AI 提示都明确包含用户已设置学历、岗位学历，并要求不要仅因学历高于最低门槛而扣分或淘汰。

## AI 设置

删除 GLM 和 DeepSeek Pro 预设。网页登录只保留此前已验证的普通模式，显示为 DeepSeek 网页，内部标识仍为 deepseek-v4-flash。旧网页 Pro 配置会迁移为普通模式，代理拒绝 Pro 请求。自定义兼容接口保留。

Pro 原本来自反代项目的模型映射，不能据此判断用户账号支持该模式。旧研究文档保留历史记录，当前能力以本次设置和组件说明为准。
