# DeepSeek 网页接入验证

本文保留接入过程的分阶段记录。当前集成版本为 13，使用网页默认模型，思考与联网分别选择；早期记录中的 Pro 选项已移除。下面的旧状态不代表当前运行状态，现行说明见项目 README。

验证日期：2026-10-01。已切换为 deepseek-web / deepseek-v4-flash，默认关闭深度思考。旧模型设置保存在 data/private-backups；旧官方 Key 未转发。原有筛选、官方岗位选择与每日配额保留。

## 已验证

- 前后端构建通过；运行后端版本为 9。
- 真实本机代理自动启动、复用和空闲停止，模型列表提供 Flash / Pro 固定适配器名称，仅监听 127.0.0.1。
- 6 项离线协议测试通过：token 格式、真实 WASM 已知样本、Unicode 与空片段切换、SET / BATCH、完成和中断、模型映射、临时聊天清理、认证和限流区分。
- Windows safeStorage 实际加密保存后可重新读取；加密不可用时拒绝明文降级。
- 模型路由不会发送旧官方 Key，独立处理思考和正文；网页额度受限不自动重试。
- 实际本机 API 与隐藏浏览器验证通过：设置页、两种网页模型切换、其他接口切换、未登录提示、错误显示、外部网页来源拒绝。
- 原 GLM 请求、需求词、0–150 配额、手动与简历入口、官方岗位分类和模拟批量回归通过。
- 新版桌面助手与 DeepSeek 官方登录窗口已打开；后续检查登录窗口保持打开。

## 2026-10-01 真实连接复核

登录凭据已保存后，桌面集成版本 11 通过 /api/llm/test 完成真实 DeepSeek 网页端请求。模型为 deepseek-v4-flash，返回预期 JSON，耗时 1397 毫秒。请求仅包含简短的连通测试内容，不含简历或职位数据。此前未验证的真实调用现已验证成功。

同时调整了 Windows 进程生命周期：本机代理独立启动，后台退出不会被动结束人工登录窗口；仍保留原有登录窗口打开时拒绝关闭服务的规则。

## 2026-10-02 思考与联网开关

设置页新增“网页功能”，提供深度思考与联网搜索两个独立开关，均默认关闭。四种组合保持相同网页默认模型，分别发送 thinking_enabled 与 search_enabled。保存后用于后续模型任务；网页登录窗口的手动选择不会修改助手设置。

已验证：

- 前后端构建通过；桌面后台集成版本 13、本机网页组件版本 2。
- 8 项离线协议测试通过，覆盖四种功能组合和联网控制标记、搜索片段、思考与最终 JSON 分离。
- 模型服务参数、凭据隔离、JSON 解析与旧 API 请求兼容测试通过；自定义 API 不会带入网页搜索参数。
- 隔离界面验证四种组合的勾选、保存、刷新后恢复，模型预设与学历设置回归通过。
- 使用已有网页登录发起一次实际请求，同时发送 thinking=true、web_search=true，约 5.0 秒返回合法 JSON，思考内容独立返回。仅查询公开的 DeepSeek 官网链接，不含简历或岗位数据，不发送 BOSS 招呼，不改变用户保存的功能设置。

旧版本本机组件仅在空闲且未显示登录窗口时自动退出后更新；忙碌或登录窗口仍打开时保留，提示用户等待或手动关闭窗口。账号资料目录与保存的网页登录凭据继续复用。
