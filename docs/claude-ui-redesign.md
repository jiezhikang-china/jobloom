# Claude 风格求职工作台

用户指定暖白与陶土色的 Claude 视觉方向。正文采用 Windows 中文无衬线字体，投递页大标题采用衬线字体。主操作使用 #AD4D31 深陶土色，保证普通字号白字可读。

颜色：背景 #FAF9F5，侧栏 #F1F0E9，表面 #FFFEFC，正文 #141413，次要文字 #66645F，边框 #E5E3D9；#D97757 为点缀色。

布局：左侧独立导航，右侧页面独立滚动。投递页左边选择简历或手动目标、职位分类、工作条件，右边固定显示真实方案概览与开始按钮。窄窗口把概览放到表单上方。

```text
窗口标题栏
左侧导航 | 页面标题、BOSS 会话
         | 目标和工作条件 | 投递概览
         | 简历/手动模式 | 城市、岗位、条件、每日数量
         |               | 开始投递
         | 待确认岗位
```

方案核对：求职工作台需要随时调整岗位、条件和控制任务，因此采用应用侧栏与固定操作区。页面不强制简历分析或优化顺序。所有子面板、地图、PDF 操作、待确认岗位、原生窗口标题和启动页使用统一主题。主状态用实际数据，键盘焦点和减少动画设置可见生效。
