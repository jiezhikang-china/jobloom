# 其他 DOM 操作节奏复核

日期：2026-10-08。承接 [人工选岗记录校准](dom-pacing-calibration.md)。

## 结论与现行间隔

普通控件与输入的间隔已经接近人工选岗中位数，不需要将全部操作统一缩短。此次修复重点是多余滚动、重复排队以及未经过原生鼠标流程的脚本点击。

| 操作 | 当前调度 |
| --- | --- |
| 选择岗位 | 按人工记录的 14 段间隔循环，0.543–3.842 秒 |
| 普通控件、悬停 | 同类开始间隔 1 秒 |
| 文本输入 | 同类开始间隔 1.2 秒；以一次填入作为一个动作 |
| 页面导航、公司页 | 同类开始间隔 2 秒，仍等待实际页面就绪 |
| 自选来源切换 | 同类开始间隔 3 秒 |
| 列表加载更多 | 同类开始间隔 5 秒，单次滚动 |
| 沟通与保存 | 距上次写入完成至少 2.5 秒 |
| 明确排除项的不合适反馈 | 距上次写入完成至少 5 秒 |
| 已发送后的继续沟通等确认 | 距上次动作开始至少 0.6 秒 |

全部操作仍经过共享队列；不同类型之间有 543ms 的开始间隔下限，原生鼠标按下至释放停留约 104ms。实际页面准备、读取和分析用时计入间隔。

原记录中的滚动以 180ms 窗口合并，未直接记录每次滚轮输入的间隔和幅度，因此没有将合并窗口当作所有 DOM 操作的间隔。

## 已修复

1. 点击和悬停不再无条件将目标滚动至屏幕中央。先计算视口与父级滚动容器的可见交集，已可见时直接在可见区域内操作；不在可见区域时才就近滚动。隐藏元素仍拒绝点击。
2. 自选职位编辑的七处脚本直接点击改用原生点击适配，覆盖编辑入口、分类选项、城市、薪资与保存，并保留原来的动作类型和队列。
3. 加载更多由“先滚到末卡，再排队滚动列表”合成一次队列动作、一次滚动。固定 900ms 等待改为最多等待 900ms，新链接或明确到底提示出现就返回。等待期间发现登录或验证状态会中止。

累计关闭浏览器休息、平台限制处理和用户明确排除项的反馈范围继续沿用现有实现。
